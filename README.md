# AstraCode Homebrew tap

```bash
brew install vrx-astracode/tap/astracode-agent
```

Installs `astracode-agent`, the [AstraCode](https://astracode.io) coding agent for
the terminal, CI jobs and scripts. macOS and Linux, arm64 and x64.

```bash
astracode-agent login
astracode-agent -p "why does the login test fail?"
```

Update with `brew upgrade astracode-agent`.

Other ways to install: `curl -fsSL https://astracode.io/install | sh`, or
`npm install -g astracode-agent`.

The formula is generated on every release; changes here are overwritten.
